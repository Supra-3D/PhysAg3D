# 当前会话依赖与复现审计

## 结论

目前没有证据证明“离开这台机器或这段聊天就一定失败”；同样，也没有证据支持“别人拿到代码就能重现当前展示效果”。**状态是未证实，不能写成已复现。**

方法的关键行为主要以 SKILL、WORKER_PROMPT、工具代码、运行参数和逐例生成脚本存在，并非只能保存在聊天记忆里。可是历史高质量结果中混有参考模板、续跑、不同版本、额外手工处理以及不完整验收，所以“有结果”本身不能排除上下文/人工/工具链的影响。

## 查到的具体证据

1. **原版和辅助版执行入口不同。** 原版 `scripts/run_api.py` 走 API-key 入口，默认 effort=xhigh；20260923 两批 worker 则明确覆盖为 ChatGPT subscription、gpt-6-astra/high。不能只公开原版 API launcher，再说它就是全部展示结果的运行方式。
2. **34 例 assisted 方法含历史代码模板。** `WORKER_PROMPT.md` 的 authority 段明确允许 `assisted_reference_code`，要求记录采用的算法。那些脚本源自早期具体案例；不是无案例先验的通用库。它们在这里完整公开并明示。如果删掉参考库，必须将“无模板版”另列实验重测，不能套用原结果。
3. **历史批处理支持本例会话续跑。** `8769_appearance20_assisted/controller_history/run_batch.py` 用 `exec resume` 恢复同一案例；这可以是该例合法的 within-run 上下文，不等于继承当前监督聊天，但需要公布续跑次数和预算。当前新 launcher 不自动实现该策略，因此尚不能认定执行过程等价。
4. **历史运行没有经过可认证的干净 guest/container 隔离。** 记录均为 `strict_isolation=false`。`--ignore-user-config`、关闭 memories 和新目录并不能证明无法读取宿主文件、AGENTS/技能或其他状态。
5. **本机配置不是可直接迁移的配置。** 旧 profile 含本机 Python/Blender、SSH 别名、权重和 jobs_root 路径。原始 skill 的历史 `server.json` 默认值甚至是 512/12/1024，而 worker 显式传入的是 1024/24/2048。新入口固定参数、替换 profile 并分配独立作业目录，防止误用默认值。
6. **50 例展示并非同一版本的独立从零生成。** 包含 assisted_continuation、generation-only、img_055 手动改色、img_056 assisted 几何修复；3 个视频仅转台。`cases.csv` 和逐例 identity 对应每个结果的来源。不能用这 50 例统一报告“完整物理验证成功率”。
7. **工具链还没有完整锁定。** 现存文件指纹覆盖主 TRELLIS 模型和 runtime 文件；完整依赖锁、第三方扩展 build、全部 DINO/BiRefNet 权重哈希仍需核对。目录名带 commit 片段不等于已提供完整可重建补丁集。
8. **模型服务也是依赖。** CLI 是可执行程序，推理模型是远端服务；模型名、effort、服务可用性及 CLI 参数都影响结果。CLI 支持差异应报错，不能绕过权限或默换模型来声称复现。

## 新包排除了什么，尚未证明什么

新准备器只打包固定方法、输入图和结构化 runtime。无额外自由文本 context 参数，不复制当前会话、日志、凭据或旧模型；native jobs_root 每例唯一；input/method/prompt/config 都有哈希。生成子进程移除继承的桌面会话环境变量，关闭 memory 和多 agent，未传 resume/fork 标识。

这证明的是**输入包可列举、可检查**，不是操作系统访问隔离。接收者自己的 clean VM/独立系统才是评估边界；不要将包含全部历史结果的目录挂载进去。验证操作应由独立记录完成，而不是修改 `strict_isolation` 字段就宣称隔离。

## 正式 release 前的阻塞项

- 在独立机器上安装所声明的工具链，确认 native runtime 文件指纹及扩展/权重清单；如本地修改了 TRELLIS，公开所需补丁。
- 选择一个固定的 worker 协议、模型/effort、预算和失败处理策略；不能继续混用 generation-only 和完整验证。
- 在不接触旧资产/聊天/案例建模指导的环境，按预登记输入清单重新生成，保留完整失败分母。
- 同时检查外观、部件归属、局部坐标绑定、可见运动和真实物理证据；不能以旧视频或元数据代替新检查。
- 复查首方代码授权、第三方许可和示例图片/资产再分发资格；这份交付没有替用户擅自指定开源许可证。

本次能交付源码、准备器和证据索引；**不能提前签发生成效果复现结论**。
