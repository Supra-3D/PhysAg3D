# 结果检查清单

每个运行目录应保留输入、方法和配置、identity、prompt、execution、events/stderr、progress、delivery、生成脚本、native 回执和候选，以及实际生成的 Blender/GLB、物理场景与依赖、轨迹或报告、渲染和视频。

首先检查 `execution.json` 和 `delivery.json`，再打开它们指向的实际文件。输出过大时，可先检查状态文件、完整错误日志以及静止、中间和端点的截图或视频，原始大文件应保留。

建议记录以下信息：

- 操作系统、Python、Blender、CLI、CUDA/PyTorch 版本和模型配置。
- 输入 SHA256、是否使用全新 native、是否发生人工指导或修复。
- 生成、细化、可见部件运动、柔性行为和物理测试各自的状态。
- 失败阶段、限制、运行耗时和全部尝试记录。

进程完成不等于资产通过。预检失败、生成失败、部分交互和完整验证通过应分别记录。共享运行结果时，不要包含个人登录目录、SSH 私钥、环境密钥或其他认证文件。
