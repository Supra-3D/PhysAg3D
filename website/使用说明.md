# PhysAg3D 最终网页

## 打开网页

在本目录双击 START_PREVIEW.bat，浏览器打开 http://127.0.0.1:8765/ 。
也可以在本目录运行 `runtime\python.exe -B launch.py`。
交互模型需要本地服务，请不要直接双击 index.html。

## 文件和素材

- index.html、styles.css、hero.css 等：最终网页；保留最初交接包排版。
- assets/film.mp4、assets/film-poster.png：用户提供的最终房间影片和封面；影片内容未改。
- assets/hero/：首页 Overview 与 Camera、Phone、Globe、Ladder、Carousel 五项视频和封面。
- assets/uniform-videos/：236项最新版视频和对应封面。
- assets/generated-latest/：236项最新版模型、输入图、资产说明及实际使用的交互数据。
- assets/gallery-models/catalog.json：当前交互资产目录。
- viewer/assets/：五个原生交互模型必需的场景、网格、纹理与控制参数。
- viewer/web/：交互界面及本地依赖；保留相应许可证。
- assets/PhysAg3D.pdf 和论文图表：研究资料。

首页先播放视频，点击视频、View detail 或 Gallery 卡片后打开详细交互界面。
物体运动能力以当前交付资产为准；软体表面响应采用现有形变数据或浏览器局部形变。
当前唱片机和咖啡机主模型为静态外观，可旋转和缩放查看。

所有交互例子的材质均通过 GLTFLoader 读取原 GLB 的完整 PBR 参数和贴图。
五个原生物理例子使用 source-materials.js 将源材质绑定到 MuJoCo 几何，
保留各自的材质索引和贴图 UV 通道；Gallery 直接加载源 GLB 材质。

## 自包含运行环境

本包适用于 Windows 10/11 64 位。Python 位于 runtime/，MuJoCo、NumPy、Pillow
及其依赖位于 .viewer-python/。双击 START_PREVIEW.bat 即可离线启动，
无需另装 Python 或联网安装依赖。完整解压后使用，整个文件夹可移动到其他目录。
启动后浏览器自动打开；关闭启动窗口即可停止服务。
默认端口8765已被占用时自动选择空闲端口。

源码也可供其他系统使用；macOS/Linux需要各自系统的Python和MuJoCo依赖。
包内runtime为Windows64位环境。所有原有第三方许可证均保留。

## 校验

双击 VERIFY_PACKAGE.bat 或运行 `runtime\python.exe -B verify_package.py` 检查 package-manifest.json 内的最终文件。
修改网页或素材后，需同步更新该清单。
